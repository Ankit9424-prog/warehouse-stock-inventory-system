## 1. Project Overview
The Warehouse Stock Inventory System is an Agile-engineered software solution designed to streamline warehouse intake, real-time inventory tracking, barcode scanning, order priority routing, automated replenishment purchase orders, and immutable audit logging.

## 4. Agile Workflow & Version Control
This project follows an Agile Scrum framework combined with a Git feature-branch workflow:
- `main` branch contains verified releases.
- Feature branches (`feature/wms-xx-...`) are used for isolated story development.
- Pull requests undergo code review and verification before merging.
- Trello is utilized for Sprint Backlog tracking, story point allocation, and burndown monitoring.
